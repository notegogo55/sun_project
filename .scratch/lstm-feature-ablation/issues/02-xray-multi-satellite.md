# 02: X-ray ต่อเนื่องข้ามดาวเทียม ครอบคลุม 2011-2024

**What to build:** กราฟฟลักซ์รังสีเอกซ์บนหน้าเว็บแสดงข้อมูลของหน้าต่าง พ.ค. 2024 ได้ ซึ่งตอนนี้
ว่างเปล่าเพราะคลังอ่านเฉพาะ GOES-15 ที่มีข้อมูลถึงปี 2017 เท่านั้น และค่าที่มาจากดาวเทียมต่างรุ่น
ต้องอยู่บนสเกลเดียวกันก่อนถูกนำไปใช้ ไม่ว่าจะใช้วาดกราฟหรือใช้เป็น feature ของโมเดลในใบถัดไป

ใบนี้ทดสอบและเห็นผลได้จบในตัวเอง **โดยไม่ต้องรอเฟรมภาพจากใบ 03**

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## พบเพิ่มระหว่างทำ (นอกขอบเขตเดิมของใบนี้)

**`.gitignore` บรรทัด `data/` (ไม่มี `/` นำหน้า) จับ `backend/src/sunseg/data/` (แพ็กเกจโค้ด
หลักของแอป 15 ไฟล์) ไปด้วย ทำให้ไม่เคย commit เข้า git เลยตั้งแต่ initial commit** — ค้นพบ
ตอนจะ commit `xray_flux.py` แล้วพบว่า git ไม่เห็นการเปลี่ยนแปลงเลย ตรวจแล้วพบว่าทั้งแพ็กเกจ
ไม่อยู่ใน git tree เลย (`git ls-files` ว่างเปล่า) แก้แล้วโดยเปลี่ยนเป็น `/data/` (ยึด root)
ยังไม่ commit — เป็นการเปลี่ยนแปลงที่กระทบวงกว้างเกินขอบเขตใบนี้ รอให้เจ้าของงานตัดสินใจ
เรื่องกลยุทธ์ commit ก่อน
