# 05: เทรนสองโมเดลหลาย seed แล้วรายงานผลต่างแบบจับคู่

**What to build:** คำตอบของทั้งโปรเจคอยู่ในใบนี้ — เทรน **SHARP-only** กับ **SHARP+intensity**
บน dataset ชุดเดียวกัน ด้วย hyperparameter เดียวกันทุกตัว ต่างกันแค่ชุด feature ที่ป้อนเข้า
แล้วตอบว่าความเข้มแสงจาก U-Net ช่วยให้พยากรณ์ flare ได้ดีขึ้นหรือไม่

สิ่งที่ต้องคุมให้เหมือนกันระหว่างสองโมเดล: ขนาดโมเดล, learning rate, loss, จำนวน epoch, กติกา
early stopping, ชุด seed, และแถวข้อมูลที่ใช้ **สิ่งเดียวที่ต่างคือจำนวนและชนิดของ feature**

การเลือก threshold ทำแยกต่อโมเดลบน validation แล้ว freeze ก่อนแตะ test — ตามกติกาที่โปรเจค
ใช้อยู่ สองโมเดลจึงถูกวัดที่จุดทำงานที่ดีที่สุดของแต่ละฝ่าย ไม่ใช่ถูกบังคับให้ใช้ค่าเดียวกัน

**วิธีสรุปผลคือหัวใจ:** test มี positive ราว 40 ตัว ซึ่ง README ของโปรเจคเองยอมรับว่า "ต่างกัน
ไม่กี่เหตุการณ์ก็ทำให้ TSS ขยับมาก" ตัวเลขเดี่ยวจึงตอบไม่ได้ว่าต่างกันจริงหรือบังเอิญ — ต้องเทรน
ทั้งสองโมเดลด้วยชุด seed เดียวกันหลายค่า **จับคู่ผลของ seed เดียวกัน** แล้วรายงาน mean±SD
ของผลต่าง ไม่ใช่แค่ mean±SD ของแต่ละโมเดลแยกกัน การเทรนใช้เวลาไม่กี่นาทีต่อครั้ง ต้นทุน
จึงแทบเป็นศูนย์

รายงานต้องแยกผลของช่วง 2017 ออกจากช่วง พ.ค. 2024 ให้เห็น — **383 จาก 420 positive ของ test
มาจากเดือนเดียวที่ AR 13664 ครองอยู่** ตัวเลขรวมก้อนเดียวจะสื่อว่า "ทำนาย AR ดวงนั้นได้ดี
แค่ไหน" มากกว่าผลทั่วไป

artifacts ทั้งหมดเขียนลง path ของงานศึกษา ห้ามทับ checkpoint และไฟล์ค่าทำนายชุดเดิมที่
หน้าเว็บใช้อยู่ และต้องเซฟค่าทำนายราย sample ในรูปแบบเดียวกับที่แผง confusion matrix อ่านได้อยู่แล้ว
