# 06: แสดงผลการเปรียบเทียบบนหน้าเว็บ

**What to build:** ให้คนที่เปิดหน้าเว็บเห็นคำตอบของงานนี้โดยไม่ต้องเปิดไฟล์รายงาน

สองส่วน:

1. **ตารางเปรียบเทียบ** ในส่วน "ผลการทดลอง" ต่อจากตารางผลเดิม — SHARP-only เทียบกับ
   SHARP+intensity พร้อม mean±SD ของผลต่าง และคำอธิบายสั้น ๆ ว่าตัวเลขนี้ตอบอะไร
2. **ขยายตัวสลับโมเดลของแผง confusion matrix จาก 2 เป็น 3 ตัวเลือก** — แผงนี้กับ endpoint
   ของมันมีอยู่แล้วครบ งานคือทำให้มันรับโมเดลของงานศึกษาได้ด้วย

**ป้ายกำกับสำคัญ:** โมเดลของงานศึกษาไม่ใช่ตัวที่ระบบใช้พยากรณ์จริง (`/api/forecast` ยังเสิร์ฟ
โมเดลรายชั่วโมงชุดเดิม) และใช้ dataset คนละชุดกับโมเดลเดิม — ต้องบอกให้ชัดตรงจุดที่คนเห็น
ไม่ใช่ซ่อนไว้ในเชิงอรรถ ไม่งั้นคนจะเทียบตัวเลขข้ามชุดข้อมูลกันโดยไม่รู้ตัว

ถ้ายังไม่มี artifacts ของงานศึกษา ส่วนนี้ต้องบอกว่าต้องรันอะไรก่อน และหน้าเว็บส่วนที่เหลือ
ต้องเปิดได้ตามปกติ ตามธรรมเนียมของแอปนี้
