# 02: เซฟค่าทำนายราย sample ตอนเทรน

**What to build:** ตอนนี้สคริปต์เทรนคำนวณค่าความน่าจะเป็นของทุก sample เพื่อทำตัวชี้วัด แล้ว
**ทิ้งไป** เก็บไว้แต่ตัวเลขสรุป ทำให้ไม่มีใครเอาผลทำนายไปทำอะไรต่อได้เลย และ baseline
logistic ก็ไม่ได้เซฟทั้งตัวโมเดลและค่าทำนาย

ให้สคริปต์เทรนเซฟค่าทำนายราย sample ของ split val และ test ลงไฟล์เดียวข้าง ๆ ไฟล์
ตัวชี้วัดที่เซฟอยู่แล้ว หนึ่งแถวต่อหนึ่ง sample ประกอบด้วย split, HARP, NOAA AR, เวลาออก
พยากรณ์, label จริง, ค่าความน่าจะเป็นจาก LSTM และค่าความน่าจะเป็นจาก baseline logistic

ไม่เก็บ split train — ทำให้ไฟล์โตขึ้นยี่สิบเท่าและชวนให้เข้าใจผิดว่าเป็นผลงาน

นี่คือฐานของทุก ticket ที่เหลือ: ตัวเลขบนหน้าเว็บต้องมาจากไฟล์นี้ ไม่ใช่จากการรันโมเดลใหม่
ตอน request เพราะโมเดลเทรนบน GPU แต่เว็บรันบน CPU — sample ที่อยู่ชิด threshold อาจพลิกฝั่ง
แล้วทำให้หน้าเว็บรายงานตัวเลขคนละชุดกับที่ README บอก
