# 04: คลิกช่องเพื่อดูรายชื่อ sample แล้วกระโดดไปดูใน dashboard

**What to build:** ทำให้แต่ละช่องของ confusion matrix คลิกได้ แล้วเห็นว่าในช่องนั้นมี active
region ดวงไหนอยู่บ้าง และกระโดดไปดูข้อมูลจริงของดวงนั้นต่อได้

ช่อง miss คือ flare ระดับ M+ ทั้งหมดที่โมเดลพลาดในชุดทดสอบ — จำนวนน้อยพอที่จะไล่ดู
ทีละดวงได้จริง งานนี้คือสิ่งที่ทำให้ confusion matrix เปลี่ยนจากภาพประกอบเป็นเครื่องมือ
ที่ใช้ตอบคำถามว่า "โมเดลพลาดตรงไหน แล้วตอนนั้นเกิดอะไรขึ้น"

สิ่งที่ผู้ใช้ทำได้เมื่อ ticket นี้เสร็จ:

- คลิกช่องใดช่องหนึ่งของตาราง แล้วเห็นรายการ sample ในช่องนั้น ณ threshold ที่สไลเดอร์
  ชี้อยู่ตอนนั้น แต่ละแถวบอก HARP, NOAA AR, เวลาออกพยากรณ์ และค่าความน่าจะเป็น
- เห็นรายการเรียงตามค่าความน่าจะเป็นจากมากไปน้อย เคสที่น่าสนใจที่สุดจึงอยู่บนสุด
  (miss ที่ "เกือบถึง" กับ false alarm ที่โมเดลมั่นใจที่สุด)
- รายการที่ยาวมาก เช่นช่อง correct negative ที่มีเกือบหมื่นแถว ถูกตัดให้เหลือเท่าที่ดูไหว
  พร้อมบอกจำนวนเต็มของช่องนั้น
- คลิก sample หนึ่งแถว แล้วหน้าเลื่อนขึ้นไปที่ dashboard โดย **เลือก AR ดวงนั้นให้และขยับ
  ช่วงวันที่ให้ครอบเวลาออกพยากรณ์ของ sample นั้น** — ถ้าตั้งแค่ AR ผู้ใช้จะเจอกราฟว่าง
  เพราะช่วงวันที่ปริยายของ dashboard อยู่คนละปีกับชุดทดสอบ
- เปลี่ยน threshold, โมเดล หรือ split แล้วรายการที่เปิดค้างไว้อัปเดตตามหรือปิดตัวลง
  ไม่ค้างแสดงข้อมูลของสถานะเก่า

ข้อกำหนดเชิงโครงสร้าง: การคัดว่า sample ไหนอยู่ช่องไหนต้องทำฝั่ง Python และเรียกเฉพาะ
ตอนคลิก — ข้อมูลราย sample ของ val มีสองหมื่นกว่าแถว ไม่ควรถูกส่งข้ามสายมาทั้งก้อน
ตั้งแต่ตอนโหลดหน้า
