# 05: บันทึกแผงใหม่และขั้นตอนที่ต้องรันลง README

**What to build:** README ของโปรเจคเป็นเอกสารหลักที่บอกทั้งขั้นตอนการใช้งานและผลการทดลอง
คนที่ clone โปรเจคไปหลังจากนี้ต้องรู้จากที่เดียวกันว่ามีแผง confusion matrix อยู่ในหน้าเว็บ
มันตอบคำถามอะไรได้ และ **ต้องรันสคริปต์เทรนซ้ำหนึ่งครั้ง** ถึงจะได้ไฟล์ค่าทำนายที่แผงนี้ใช้
(คนที่มี checkpoint เก่าอยู่แล้วจะเห็นแผงขึ้นข้อความบอกวิธีแก้แทนตาราง ซึ่งเป็นพฤติกรรม
ที่ตั้งใจ ไม่ใช่ bug)

เขียนด้วยศัพท์ชุดเดียวกับที่ README ใช้อยู่แล้วในหัวข้อตัวชี้วัดและผลการทดลอง และอธิบายด้วยว่า
ทำไมตารางถึงเรียงแบบ forecast × observed ตามธรรมเนียมของวงการ space weather ไม่ใช่แบบ
ที่ไลบรารี ML ทั่วไปใช้
