# 01: ลบสำเนาหน้าเว็บที่ตายแล้วออกจาก repo

**What to build:** ใน repo มีหน้าเว็บสองชุด — ชุดที่ผู้ใช้เห็นจริง กับสำเนาเวอร์ชันเก่าใต้แพ็กเกจของ
FastAPI ที่ไม่มีโค้ดส่วนไหนอ้างถึงเลยแต่ยังถูกใส่เข้า Docker image อยู่ ลบสำเนาที่ตายแล้วทิ้ง
เพื่อให้เหลือหน้าเว็บชุดเดียวใน repo — คนที่มาทำงานต่อจะได้ไม่แก้ผิดไฟล์แล้วงงว่าทำไม
หน้าเว็บไม่เปลี่ยน

งานนี้ไม่เปลี่ยนสิ่งที่ผู้ใช้เห็นแม้แต่พิกเซลเดียว — ทำก่อนเพื่อให้ ticket ที่เหลือแก้ไฟล์ได้โดย
ไม่ต้องลังเล

**Blocked by:** ไม่มี (เริ่มได้ทันที)

**Status:** ready-for-agent

- [ ] ค้นทั้ง repo แล้วยืนยันว่าไม่มีโค้ด, config, test, Dockerfile หรือเอกสารใดอ้างถึงสำเนานั้น
- [ ] ลบสำเนาที่ตายแล้วออกทั้งหมด เหลือหน้าเว็บชุดเดียว
- [ ] เปิดเซิร์ฟเวอร์แล้วหน้าแรกยังแสดงผลเหมือนเดิมทุกอย่าง รวมทั้งไฟล์ static ทุกตัวโหลดได้ (ไม่มี 404)
- [ ] `pytest` ผ่านทั้งชุดเหมือนก่อนแก้
- [ ] build Docker image แล้วเปิดหน้าเว็บใน container ได้ตามปกติ
