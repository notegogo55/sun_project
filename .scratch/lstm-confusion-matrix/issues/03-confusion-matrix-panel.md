# 03: แผง confusion matrix พร้อมสไลเดอร์ threshold

**What to build:** เพิ่มบล็อกใหม่ในส่วน "เกี่ยวกับงานนี้" ของหน้าเว็บ ต่อจากตารางผลการทดลอง
และการแบ่งข้อมูล: ตาราง 2×2 ที่ผู้ใช้เลื่อน threshold ดูได้ทันที

สิ่งที่ผู้ใช้ทำได้เมื่อ ticket นี้เสร็จ:

- เห็นตาราง 2×2 ที่ **แถวคือสิ่งที่โมเดลทำนาย คอลัมน์คือสิ่งที่เกิดขึ้นจริง** เรียง positive ก่อน
  ตามธรรมเนียม contingency table ของวงการ space weather แต่ละช่องมีทั้งชื่อทางสถิติ
  (TP/FP/FN/TN) และคำเรียกของวงการ (hit / false alarm / miss / correct negative)
  พร้อมจำนวนนับและสัดส่วนของแถว
- เลื่อนสไลเดอร์ threshold แล้วตัวเลขทั้งสี่ช่องกับตัวชี้วัด (TSS, recall, precision, HSS2)
  เปลี่ยนทันทีโดยไม่มีการรอโหลด
- เห็นตำแหน่งของ threshold ที่ระบบ freeze ไว้บนสไลเดอร์ และกดกลับไปที่ค่านั้นได้ในคลิกเดียว
- สลับดูระหว่าง LSTM กับ logistic baseline โดยสไลเดอร์รีเซ็ตไปที่ threshold จาก validation
  ของโมเดลที่เพิ่งสลับมา (สองโมเดลมีจุดทำงานคนละค่าและสเกลความน่าจะเป็นไม่ตรงกัน —
  ห้ามให้สไลเดอร์ตัวเดียวคุมสองโมเดลพร้อมกัน)
- สลับดูระหว่าง split test (ค่าเริ่มต้น) กับ val โดย val ติดป้ายชัดว่าเป็นชุดที่ใช้เลือก threshold
  ไม่ใช่ตัวเลขที่รายงาน และเห็นจำนวน sample กับจำนวน positive ของ split ที่กำลังดูอยู่

ข้อกำหนดเชิงโครงสร้างที่ห้ามละ:

- **การนับอยู่ฝั่ง Python เสมอ** — เพิ่มฟังก์ชันกวาด threshold เข้าไปในโมดูลตัวชี้วัดของโปรเจค
  (ที่มี test คุมอยู่แล้ว) แล้วให้ endpoint คืนตารางจำนวนนับล่วงหน้าของทุกจุดในกริดเดียวกับที่
  โปรเจคใช้เลือก threshold อยู่แล้ว หน้าเว็บมีหน้าที่แค่เปิดตารางที่ index ตามสไลเดอร์และ
  คำนวณตัวชี้วัดจากจำนวนนับสี่ตัวด้วยเลขคณิตล้วน — ห้ามย้ายการนับ TP/FP/TN/FN ไปไว้ใน JS
  ซึ่งไม่มี test เลยสักตัว
- **สไลเดอร์ห้ามรั่วออกนอกแผง** — ค่าที่ผู้ใช้ลากต้องไม่ไปเปลี่ยน threshold ที่ระบบใช้ตัดสิน
  ความเสี่ยงให้กับ dashboard ส่วนอื่น
- **เรนเดอร์เป็นตาราง HTML/CSS ไม่ใช่ Plotly** แม้กราฟอื่นทั้งหมดจะใช้ Plotly — เพราะ
  correct negative มีเกือบหมื่นส่วน miss มีสิบกว่า การไล่สีตามจำนวนนับจะทำให้สามช่อง
  กลายเป็นสีเดียวกันหมด ให้ลงสีตามบทบาทของช่องแทน และอ่านสีจาก CSS custom property
  จุดเดียวตามที่โปรเจคทำอยู่
- **degrade อย่างสุภาพ** — ถ้ายังไม่มีไฟล์ค่าทำนาย แผงต้องบอกว่าต้องรันสคริปต์ไหน และ
  หน้าเว็บส่วนที่เหลือต้องเปิดได้ตามปกติ

**Blocked by:** 01 (ลบสำเนาหน้าเว็บที่ตายแล้ว), 02 (เซฟค่าทำนายราย sample ตอนเทรน)

**Status:** ready-for-agent

- [ ] endpoint สรุปคืนตารางจำนวนนับครบทุกจุดของกริด พร้อม threshold ที่ freeze ไว้, AUC และขนาดของ split
- [ ] threshold ที่ freeze ไว้ตกอยู่บนจุดของกริดพอดี ไม่ต้องปัดเศษ
- [ ] จำนวนนับ ณ threshold ที่ freeze ไว้ตรงกับที่ไฟล์ตัวชี้วัดรายงานทุกช่อง ทั้งสองโมเดลและทั้งสอง split — มี test ยิงผ่าน HTTP จริง

- [ ] สลับโมเดลแล้วสไลเดอร์เด้งไปที่ threshold ของโมเดลนั้น สลับ split แล้วขนาดชุดที่แสดงเปลี่ยนตาม
- [ ] ตารางและตัวควบคุมยังอ่านได้บนจอแคบ
- [ ] ขยับเลขเวอร์ชันท้าย URL ของไฟล์ static ที่แก้ ไม่งั้นเบราว์เซอร์เดิมจะยังใช้ไฟล์เก่า
